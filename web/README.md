# Compex
a freemium platform for users to prepare for competitive exams like GRE, GMAT and CAT. 
current project status: (09/12/2024)

## Unregistered User (Rs 0.)
* Access to Main home page
* Access to Vocabulary page

## Free Version (Rs 0.)
* Users can check the dashboard page
* Users can solve all the newly generated questions in the problems section.
* Users must have to give the feedback of all the questions that they have solved {there will be shortcut for doing that for faster and smoother convenient interactivity}

* Users will get popular questions with good feedback from audience who are going to use the service for free.

## Key features
* Questions will be generated by ChatGPT, thus there will be a lot of questions available.
* User can solve questions based on a specific category, difficulty level,specific question style, mock test etc.
* There will be a dashboard page where the user can cross check their performance overall.
* There will be a leaderboard page where the user can check their ranking.
* User can provide feedback of the question on result page. 

## Design
* Interactive and engaging design to keep the user engaging at the time of solving the questions
* Consistent and simplistic in design for easy understanding.
* Questions designed on question page are auto-adjustable with precise graphs and chart which will be displayed.
* Question designed for Reading comprehension will be developed in such a way that Passage is displayed for all the child questions.
* Various charts will be used in the dashboard page to demonstrate the performance of the user on accuracy, question style, rate of inprovement
* User's daily input for streak maintainence and daily involvement visualization on the dashboard page just like github's main page.

## Internal architecture
* based on number of users feedback, overall accuracy and number of users attempted that question, the popularity index of that question will be created.
* Users can solve questions based on popularity index of that question.
* Proper distribution of Questions based on QuestionTheme, QuestionStyle, question type, Difficulty level. etc.
* User's absolute reports will be stored, thus presenting analysis on the dashboard based on the user's first response of that particular question.
* A distributed server based on requirement {QuestionGeneration Server (getting questions generated from AI and storing in DB), Main Website Server (), Analysis server (a separate machine to calculate the popularity index, doing calculation for leaderboard ranking and storing it in the database)}


## Folder structure
* **API_Instrucitonsets**: list of readme files that contains the instruction sets for creating the respective type of questions, all the files are present in markdown format. These instructions are shared to ChatGPT assistant APIs.
* **CheckData**: a sensitive folder for development purpose only, key responsibilty is to check what type of data is being stored in the tables and if necessary deletion of secondary/tertiary data.
* **compex**: This folder consists of complete front-end and back-end files
* **Development Plannning**: this folder consists of files defining milestones and expected time taken to achieve that milestone.
* **docker_postgres_db**: This folder is now redundant, once the execution of complete seeding is fully functional via QuestionGen - a formal approach, then this sub-folder will be removed.
* **QuestionGen**: this consists file for another server, responsible to generate question input prompt -> sending question prompts to ChatGPT assistant API -> fetching the respective Batch of question data from the API and storing it in the database. before starting adding the question data, it also ensures if the database is existing + standard infromation is present or not, if not present then that will be completed first and then this execution will happen.
* **Rough Design**: this consists rough diagrams about how a particular page of the website would look like.
* **TrySVG**: this folder is testing if the SVG diagram generated is relevant to the question created or not.
* **DB_Design.drawio**: this is having the current design of the database, it will keep on changing and in order to maintain the consistency database migration scripts should be created to make changes in the previously existing data to migrate to the database with new metadata rules.
