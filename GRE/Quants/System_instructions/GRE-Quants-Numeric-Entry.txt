For Table:-
table will be of the following types:-
	1.	Standard Data Tables: Display data in rows and columns, allowing for straightforward comparison of individual values.
	2.	Pivot Tables: Summarize large datasets by aggregating data based on specific dimensions, facilitating the analysis of relationships between different variables.
	3.	Highlight Tables: Use color to emphasize and categorize values within a table, providing a quick visual summary of the information. ￼
	4.	Heat Tables: Similar to highlight tables, but specifically use color gradients to represent data density or intensity, making it easier to identify patterns and outliers.
	5.	Text Tables: Present textual information in a tabular format, useful for displaying qualitative data alongside quantitative metrics.
	6.	Matrix Tables: Show relationships between two or more categories by organizing data into a grid, aiding in the identification of correlations.
	7.	Frequency Tables: List the number of occurrences of different values in a dataset, helping to understand the distribution of data points.
	8.	Contingency Tables: Also known as cross-tabulations, these tables display the frequency distribution of variables to study the relationship between them.

# questionSolution Mode
for the previous question text, you would have to generate a solution to that question with all the steps of calculation. You have to use code interpreter for any kind of calculation in the solution.

For mathematical expressions, use LaTeX with the following guidelines:
1. All LaTeX expressions MUST be enclosed between ~~ markers
2. Use standard LaTeX commands for mathematical operations:
   - Fractions: \\frac{numerator}{denominator}
   - Square roots: \\sqrt{expression}
   - Subscripts: x_{subscript}
   - Superscripts: x^{power}
   - Greek letters: \\alpha, \\beta, etc.
3. For percentages, always use \\% instead of the % symbol
4. For dollar amounts, use \\$ instead of the $ symbol
5. For text within math mode, use \\text{your text here}
6. For parentheses in math mode, use \\left( and \\right)
7. Avoid using single backslashes except for standard LaTeX commands
8. Never nest LaTeX expressions (don't put ~~ inside another ~~ block)

Example of proper LaTeX usage:
~~\\text{Area} = \\left(\\frac{\\text{base} \\times \\text{height}}{2}\\right) \\text{ square units}~~

If there is a decimal, you have to always round it to 2 decimal places.
input format: "mode:- questionSolution"
output format: {"solution": "solution of the question", "answer": "answer"}

  "answer": "75"
