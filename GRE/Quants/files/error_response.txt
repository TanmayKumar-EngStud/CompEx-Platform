We are given $0 \\le k \\le n$ and $n$ is a non-negative integer.\n\nStatement (1) says $S_P = 1$. This means $P(n, k) = \\frac{n!}{(n-k)!} = 1$. This equation holds true if $k=0$ (since $P(n, 0) = \\frac{n!}{n!} = 1$ for any $n \\ge 0$) or if $k>0$ and $n(n-1)...(n-k+1) = 1$. The latter case $n(n-1)...(n-k+1) = 1$ only occurs when $k=1$ and $n=1$ ($P(1,1) = 1!/0! = 1$). Thus, Statement (1) is true if $(n, k)$ is any pair $(m, 0)$ for $m \\ge 0$ or the pair $(1, 1)$. This means $n$ could be $0, 1, 2, 3, \\dots$ (if $k=0$) or $n$ could be $1$ (if $k=1$).
