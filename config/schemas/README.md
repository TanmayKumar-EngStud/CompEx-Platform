# Schema Definitions

This directory contains Python files that define various schemas used for validation throughout the question generation system. These schemas ensure that data structures are consistent and valid.

## Files

- **`instruction_schemas.py`**: This file defines the schemas for system instructions. These schemas are used to validate the format and content of instructions provided to the generation models.

- **`question_schemas.py`**: This file defines the schemas for the questions themselves. It ensures that all generated questions, solutions, and metadata adhere to a predefined structure.

- **`validation_schemas.py`**: This file contains general-purpose validation schemas that can be used across different parts of the system to ensure data integrity.
