# Generator Configurations

This directory contains JSON files that define the question generators available for each exam. These files map question types to specific generator classes and provide metadata for the generation process.

## Files

- **`gmat_generators.json`**: This file lists the available question generators for the GMAT exam. It includes information about which generators to use for each section of the exam, along with any specific configurations or parameters.

- **`gre_generators.json`**: This file lists the available question generators for the GRE exam. It provides a similar mapping of generators to exam sections for the GRE.
