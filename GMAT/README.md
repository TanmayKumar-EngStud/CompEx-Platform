# GMAT Directory

This directory contains all the files and configurations specific to the GMAT exam. It is organized into subdirectories, each responsible for a specific section of the GMAT exam.

## Subdirectories

-   **Integrated_Reasoning**: Contains the logic and files for the Integrated Reasoning section.
-   **Mock_prompts**: Holds the prompts used for generating GMAT mock exams.
-   **Quants**: Contains the logic and files for the Quantitative section.
-   **Verbal**: Contains the logic and files for the Verbal section.

For more detailed information on the functionality and data flow within each subdirectory, please refer to the `README.md` file within that specific subdirectory.
