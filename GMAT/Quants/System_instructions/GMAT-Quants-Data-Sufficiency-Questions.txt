For Table:-
table will be of the following types:-
	1.	Standard Data Tables: Display data in rows and columns, allowing for straightforward comparison of individual values.
	2.	Pivot Tables: Summarize large datasets by aggregating data based on specific dimensions, facilitating the analysis of relationships between different variables.
	3.	Highlight Tables: Use color to emphasize and categorize values within a table, providing a quick visual summary of the information. ￼
	4.	Heat Tables: Similar to highlight tables, but specifically use color gradients to represent data density or intensity, making it easier to identify patterns and outliers.
	5.	Text Tables: Present textual information in a tabular format, useful for displaying qualitative data alongside quantitative metrics.
	6.	Matrix Tables: Show relationships between two or more categories by organizing data into a grid, aiding in the identification of correlations.
	7.	Frequency Tables: List the number of occurrences of different values in a dataset, helping to understand the distribution of data points.
	8.	Contingency Tables: Also known as cross-tabulations, these tables display the frequency distribution of variables to study the relationship between them.
Output format of the following table types:-
When requesting ChatGPT to generate various types of tables in JSON format, it’s essential to structure the output appropriately to facilitate easy parsing and visualization. Below are examples of JSON formats for different table types:

1. Standard Data Table

A simple table with rows and columns.

{
  "headers": ["Column1", "Column2", "Column3"],
  "rows": [
    ["Data1", "Data2", "Data3"],
    ["Data4", "Data5", "Data6"]
  ],
  "type": "standard data table",
  "description": "description telling what this standard data table is about"
}

2. Pivot Table

Summarizes data by aggregating values across two or more dimensions.

{
  "index": ["Category1", "Category2"],
  "columns": ["Metric1", "Metric2"],
  "data": {
    "Category1": {"Metric1": 10, "Metric2": 20},
    "Category2": {"Metric1": 30, "Metric2": 40}
   },
   "type": "pivot table",
   "description": "description telling what this pivot table is about"
}

3. Highlight Table

Similar to a standard table but includes formatting details to highlight specific cells.

{
  "headers": ["Item", "Value"],
  "rows": [
    {"data": ["Item1", 100], "highlight": true},
    {"data": ["Item2", 50], "highlight": false}
  ],
  "type": "highlight table",
  "description": "description telling what this highlight table is about"
}

4. Heat Table

Represents data intensity using color gradients.

{

Lists the frequency of occurrences for different categories.

Displays the frequency distribution of variables to study the relationship between them.
