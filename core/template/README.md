# Question Template

This directory contains the template for the question generation system. Each file defines the structure for a specific part of the question.

## Files

- **`question_answer.py`**: This file defines the template for the answer to a question.

- **`question_metadata.py`**: This file defines the template for the metadata associated with a question.

- **`question_options.py`**: This file defines the template for the options of a multiple-choice question.

- **`question_solution.py`**: This file defines the template for the solution to a question.

- **`question_text.py`**: This file defines the template for the text of a question.

- **`question_title.py`**: This file defines the template for the title of a question.
